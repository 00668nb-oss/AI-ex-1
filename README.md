# MuseumMind – העוזר החכם של "מוזיאון מסע בזמן"

בוט RAG שעונה על שאלות **רק** מתוך מסמכי המוזיאון הדמיוני (קטלוג מוצגים, תערוכות ומידע למבקרים, דוחות שימור, מסמכי מחקר) ומציג מקורות לכל תשובה.

## הרצה

```
pip install -r requirements.txt
copy .env.example .env      # והדביקי OPENAI_API_KEY
python ingest.py            # בניית האינדקס ב-ChromaDB (פעם אחת, וכל שינוי ב-data)
python -m streamlit run app.py
```

## ארכיטקטורה

`data/*.txt` → SentenceSplitter → Embeddings → ChromaDB → (שאלה) → Similarity Search → סינון לפי סף → LLM → תשובה + מקורות

## ההחלטות

| נושא           | החלטה                                      |
| -------------- | ------------------------------------------ |
| Vector DB      | ChromaDB (מקומי, נשמר בתיקיית `chroma_db`) |
| ספרייה         | LlamaIndex                                 |
| חלוקה          | לפי טוקנים, SentenceSplitter, 500 טוקנים   |
| חפיפה          | 100 טוקנים                                 |
| Top K          | 5                                          |
| מודל embedding | text-embedding-3-small                     |
| מודל תשובה     | gpt-4o-mini                                |
| הרחבת שאלה     | כבויה כברירת מחדל; מתג ידני בסרגל הצד      |
| סוג חיפוש      | Similarity Search (בלי Hybrid בשלב זה)     |
| ממשק           | Streamlit                                  |

## מניעת "המצאות"

לא סומכים רק על הוראה "אל תמציא":

1. **סף רלוונטיות** (`MIN_SCORE=0.28` ב-`rag.py`) – אם אף קטע לא עובר, מחזירים "אין מידע" בלי לקרוא ל-LLM.
2. **פרומפט** שמורה להודות כשהמידע חסר או חלקי.
3. **מקורות** מוצגים לכל תשובה (קובץ, ציון דמיון, הטקסט עצמו).
4. **בדיקה בפועל** – ראי שאלות הבדיקה למטה.

## 3 בעיות שנתקלתי בהן ומה הפתרון

1. **התקנת החבילות נכשלה** (`ModuleNotFoundError: chromadb`, ואחר כך `WinError 32`). **פתרון:** שתי הרצות של `pip install` רצו במקביל והתנגשו על אותם קבצים. עצרתי את התהליכים התקועים והרצתי התקנה אחת בלבד.
2. **ציוני הדמיון נמוכים בעברית, והפער בין תשובה נכונה לשאלה מחוץ לתחום קטן.** תשובות נכונות קיבלו 0.30–0.34, ושאלה מחוץ לתחום (פיצה, מונדיאל) 0.22–0.27. סף של 0.30 היה על הקו. **פתרון:** מדדתי ציונים בפועל על שאלות בתחום ומחוצה לו וקבעתי `MIN_SCORE=0.28`.
3. **שאילתות קצרות נכשלות בחיפוש.** `TM-004` קיבל 0.23 ו-"שעון כיס" 0.296, ולכן הוחזר "אין מידע" למרות שהמידע קיים. **פתרון:** בלי קריאת AI נוספת, הוספתי כללים פשוטים: מספר קטלוג או דוח (`TM-004`, `CR-2025-03`) מחפש התאמת טקסט מדויקת ב-ChromaDB, ושאילתה של עד שתי מילים הופכת ל-"מה זה ...?". הרחבה בעזרת AI נשארה מתג ידני. אם זה לא יספיק, השלב הבא הוא BM25/Hybrid.
